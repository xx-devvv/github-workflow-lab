# GitHub workflow lab

A public, disposable practice repository for Git and GitHub workflows. It is also a transparent sandbox for learning how profile achievements are recorded. It contains practice documentation rather than production application changes.

All work in this lab stays here. No existing project needs to be edited, rewritten, or deployed. Examples are written for PowerShell and a scratch clone; replace placeholders before running them.

## Boundaries

- Each pull request documents one distinct Git operation.
- There are no deployments, paid services, API credentials, or executable GitHub Actions.
- No automated starring, fake collaborators, or fabricated reviews are part of this lab.
- Achievement eligibility and display timing are controlled by GitHub; a completed action does not guarantee an immediate badge.
